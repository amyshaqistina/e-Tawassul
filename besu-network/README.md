# e-Tawassul Besu Network

A 4-node permissioned Ethereum network using **Hyperledger Besu** with **QBFT 2.0 consensus** — the modern successor to JP Morgan's Quorum, maintained by ConsenSys.

This network anchors crisis-event hashes from the e-Tawassul Laravel application.

---

## Architecture

| Node | IP | Role | Exposes |
|---|---|---|---|
| `besu-node-1` | 172.16.239.11 | Validator | JSON-RPC on host port **8545** |
| `besu-node-2` | 172.16.239.12 | Validator | internal only |
| `besu-node-3` | 172.16.239.13 | Validator | internal only |
| `besu-node-4` | 172.16.239.14 | Validator | internal only |

- **Chain ID:** 1337
- **Consensus:** QBFT 2.0 (Byzantine fault tolerant; tolerates 1 failed node out of 4)
- **Block time:** ~5 seconds
- **Gas price:** 0 (free transactions on private chain)

## First-time setup

### 1. Generate validator keys + genesis

In PowerShell, from this folder:

```powershell
.\setup.ps1
```

If PowerShell blocks the script with an execution policy error:

```powershell
PowerShell -ExecutionPolicy Bypass -File .\setup.ps1
```

This will:
- Pull the Besu Docker image (~500 MB, first run only)
- Generate 4 cryptographically random secp256k1 keypairs
- Build a QBFT genesis file with the validator addresses baked in
- Build the static-nodes.json peering manifest

You only need to run this **once**, or whenever you want a fresh chain.

### 2. Start the network

```powershell
docker-compose up -d
```

Wait ~30 seconds for all 4 nodes to discover each other and start producing blocks.

### 3. Verify it's running

```powershell
.\test-rpc.ps1
```

Expected output: latest block > 0, chain ID = 1337, 3 connected peers, 4 QBFT validators listed.

## Daily operations

| Task | Command |
|---|---|
| Start the network | `docker-compose up -d` |
| Stop the network (keep chain data) | `docker-compose stop` |
| Stop and remove containers (keep volumes) | `docker-compose down` |
| Stop and **wipe all chain data** | `docker-compose down -v` |
| Watch node 1 logs in real time | `docker-compose logs -f besu-node-1` |
| Show last 50 lines of all nodes | `docker-compose logs --tail=50` |
| Check container status | `docker-compose ps` |

## Troubleshooting

**Network won't start: "address already in use" port 8545**
Something else is using port 8545. Find it with `netstat -ano | findstr 8545` and either stop it, or change the host-port in docker-compose.yml.

**Network starts but block stays at 0**
Wait ~30 seconds. QBFT needs all 4 nodes to handshake before producing blocks. If still stuck after a minute, check `docker-compose logs besu-node-1` for errors.

**`docker run` fails on setup.ps1**
Docker Desktop isn't running. Open it, wait for the whale icon in the system tray to stop animating, retry.

**setup.ps1 fails with "PowerShell execution disabled"**
Run with: `PowerShell -ExecutionPolicy Bypass -File .\setup.ps1`

**Want a clean restart?**
```powershell
docker-compose down -v
.\setup.ps1
docker-compose up -d
```
